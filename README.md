# YourCode for Windows

YourCode is a lightweight landing page for an offline Windows app that provides
Python coding challenges with bundled Python, instant judging, local saves, and
sandboxed runs.

The site links visitors to the latest Windows installer release.

## Tech stack

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Vite

## Development

Install dependencies and start the development server:

```sh
bun install
bun run dev
```

Open the local URL shown in the terminal.

## Build and preview

```sh
bun run build
bun run preview
```

The project can be deployed to Vercel using the **TanStack Start** preset and
the default `bun run build` command.
